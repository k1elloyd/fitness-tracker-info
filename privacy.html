Fitness Tracker Privacy Policy

Last updated: 3 November 2026

Who uses this app

Fitness Tracker is a personal app built and used by one person to view their own health and fitness data. It is not available to the public.

What data it accesses

With the user's permission, the app reads the following from the Google Health API, read-only: activity and fitness data (steps, distance, workouts), health metrics and measurements (weight, resting heart rate, heart rate variability) and sleep data. It does not write, edit or delete any Google Health data.

How the data is used and stored

The data is used only to display charts and trends to the same user. It is stored on a private server in the user's home and is not accessible from the internet.

Sharing

Data is not sold, shared with or transferred to any third party, and is not used for advertising or to train AI models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Stored data can be deleted from the private server at any time.
